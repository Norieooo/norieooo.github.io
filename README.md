# 群友同位体：测测你更像哪个群友

本版本包含 30 道题、每题 5 个选项、10 位群友的头像与完整昵称，以及单人 / 并列结果的人设分析。保留黑白灰界面、手机适配、题号导航、刷新继续、回看修改和重新测试。

头像保留原图颜色，其他界面以黑白灰为主。文件名中的“用户注”未纳入昵称；两位“今天的风好大……”分别保留。

## 本地预览

解压后双击 index.html，点击“开始测试”。也可以直接打开 quiz.html。不要只移动 HTML，需保留所有脚本、样式和 assets 文件夹。

## 上传 GitHub Pages

将本文件夹中的全部文件和 assets 文件夹上传到仓库根目录，不要上传 ZIP 本身。index.html 应直接位于仓库根目录。已有旧版网页时更新为本版本文件，并新增完整 assets/avatars 文件夹。

仓库 Settings → Pages，选择 Deploy from a branch → main → / (root)，保存。代码无需安装依赖或构建。

## 修改内容

- quiz-config.js：30 道题、选项、计分、人设、头像路径与结果文案。
- config.js：首页介绍与玩法说明，不包含具体群友展示。
- assets/avatars：10 张本地头像，文件名使用英文编号，避免部署路径问题。
- group.css：本主题的头像、长昵称、结果卡与 30 题导航样式。
- quiz.js / quiz-engine.js：问卷交互与纯计分逻辑。

每个选项给两位群友各加 5 分；每题覆盖全部群友。得分最高者展示为结果，最高分并列时全部展示，不随机强行取一人。分布百分比表示答案权重占比，不是相似概率。可以修改权重，但建议保持每题各候选人的得分机会均衡，并在改动后检查每个人都能成为第一名。

头像与昵称只作为虚构娱乐人设的创作灵感，结果不代表群友的真实性格。所有人设台词都是创作，并非本人真实发言。与夸张昵称有关的设定不推断现实私生活。

答案只存当前标签页的 sessionStorage，不上传，不需要登录。刷新可以继续；关闭标签页后进度通常清除。更换题目、选项或计分规则后增加 quiz-config.js 的 version，以免沿用旧进度。

首页和测试开始页均不展示群友头像或昵称；完成问卷后才在结果页揭晓。
